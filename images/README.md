# รูปภาพสำหรับเว็บไซต์ NB Accounting

วางไฟล์รูปที่คุณสร้างไว้ในโฟลเดอร์นี้ตามชื่อที่กำหนด

## ชื่อไฟล์ที่ต้อง save

| ชื่อไฟล์ | รูปอะไร | ขนาดแนะนำ |
|---|---|---|
| `logo.png` | โลโก้ NB Accounting (สี่เหลี่ยมสีฟ้ามีตัว NB + ข้อความ) | 512×512 px |
| `hero-banner.png` | แบนเนอร์ NB Accounting สีฟ้ามีไอคอน document/visa | 1024×1024 px (หรือ 1200×630 สำหรับ OG) |
| `ceo.png` | ผู้ชายใส่แว่น สูทน้ำเงินในออฟฟิศ (CEO / Founder) | 800×800 px, 1:1 |
| `exec-female.png` | ผู้หญิง สูทน้ำเงิน เสื้อขาว (Co-Founder / COO) | 800×800 px, 1:1 |
| `exec-male.png` | ผู้ชาย เสื้อฟ้าอ่อน แขนไขว้ (Head of Visa) | 800×800 px, 1:1 |
| `team-group.png` | รูปทีม 5 คนยืนในออฟฟิศ | 1400×780 px, 16:9 |
| `office.png` | ภาพออฟฟิศภายใน พร้อมผนังสีฟ้า | 1400×900 px, 16:10 |

## วิธี save รูปจาก chat

1. คลิกขวาที่รูปใน chat → "Save image as..."
2. ตั้งชื่อตามตาราง
3. วางในโฟลเดอร์ `images/` นี้

หลังวางรูปครบ เปิด `demo.html` ได้เลย
